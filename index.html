About

Software Engineer specialising in AI/ML and backend systems, currently pursuing a Master of Software Engineering at Yoobee Colleges in Auckland, New Zealand. I hold a BSc (Hons) in Artificial Intelligence and Data Science and have professional experience across machine learning engineering and IT support.

My work spans backend services, machine learning pipelines, computer vision, RAG/LLM applications, cloud deployment, and edge inference, with experience taking ideas from experimentation through to practical systems used in real-world environments.

Alongside industry experience, I have contributed to peer-reviewed research in image colorization and dataset development. My focus is on building reliable, maintainable, and production-ready software systems that combine strong engineering with applied AI.

ParkDirect

Designed and built an end-to-end automated vehicle access control system combining licence-plate detection and OCR with backend booking workflows and edge-triggered gate control. The system supports mobile pre-booking, real-time vehicle identification, cloud-connected services, and ONNX-based inference to automate secure entry with minimal manual intervention.

Yoobee Knowledge Assistant

Developed a RAG-based knowledge assistant using publicly available Yoobee website content. Built the pipeline to extract, clean, chunk, embed, retrieve, and rerank information, enabling the assistant to answer student and course-related questions with relevant source context.

ReIDVision

Designed and built a two-stage person re-identification system combining YOLOv8-based person detection with a custom Siamese CNN for identity matching across frames and camera views. Trained on a custom CCTV dataset of 50 identities and 10,765 labelled instances, with the final model exported to ONNX for deployment and system integration.

Colorfy

Developed an AI-based image colorization system for general grayscale images, with a particular focus on improving colour accuracy and consistency for tan-skinned human subjects. Fine-tuned and retrained an encoder–decoder model using the TanVis dataset, integrated transformer-based feature extraction, and built a Streamlit interface for interactive testing and visualisation.

  • Transformers
  • Encoder–Decoder

Smoke & Fire Detection

Developed a real-time smoke and fire detection system using YOLOv7 for continuous CCTV-based safety monitoring. Trained the model from scratch to distinguish smoke, fire, and combined smoke–fire scenarios, and evaluated it across varied indoor and outdoor environments to support fast, reliable early detection.
